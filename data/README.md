# Observatory Data

Only **presentation-safe exported data** belongs here.

Each dataset has its own directory containing a `manifest.json` plus one or more World-Day snapshot files. The browser loads the manifest first and follows only the paths declared there.

`demo/` is a synthetic contract fixture used to prove the UI and validator. It is not Witcher canon and it is not generated from the Living World engine.

Future real datasets should be generated by the authoritative engine-side sanitizer/exporter, then validated here before publication.

Never place raw save files, private GM state, internal evolution ledgers, world seeds, receipts, checkpoint SHAs, or protected provenance in this directory.
